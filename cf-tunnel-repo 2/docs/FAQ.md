# 常见问题

## 隧道相关

**域名多久换一次？**
默认不看时间，只在「连续 2 次健康检查失败」或「年龄超过 MAX_TUNNEL_AGE（默认 3 天）」时换。

**换隧道会断多久？**
新隧道先起来并验证通过，才上报、才杀旧隧道。中间有 90 秒重叠期，理论不断流。实际切换瞬间可能丢 1~2 秒。

**可以固定域名吗？**
可以。用 Cloudflare Named Tunnel（免费不限流量），配一个自己的域名。但需要域名，且 `--region` 参数只接受 `us/eu/apac/auto`，填不了具体城市。

## 性能相关

**为什么 Argo 优选 IP 很重要？**
Argo/Quick Tunnel 靠 SNI/Host 路由，目标 IP 可以任意换（任何 CF IP 都行）。优选 IP 只决定「入口段」质量，回源段（隧道到服务器）质量由服务器线路决定。

**延迟低就等于快吗？**
不等于。实测有节点延迟 39ms 全绿但带宽 0 Mbps，也有延迟 82ms 但能跑 70 Mbps 的。延迟测试只发几百字节探针，发现不了带宽崩塌。

**为什么先快后慢？**
大概率是三层叠加：①服务商出口限速 ②Cloudflare Quick Tunnel 配额 ③大量节点压少量隧道。这套方案只能缓解 ②。

## 安全相关

**REPORT_TOKEN 泄露会怎样？**
别人能把你的隧道域名改指向别处 —— 订阅会失效，但不会泄露节点密钥（密钥在订阅内容里）。

**订阅地址泄露会怎样？**
别人能拿到你的节点配置。建议订阅 ID 用足够长的随机串。

**Worker 是公开的吗？**
是。任何人知道你的 Pages 域名都能访问首页和一键脚本。但 `/api/report` 需要 Bearer token，没有 token 改不了。
